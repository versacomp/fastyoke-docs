# Cross-App Connections

When you install two apps that work with the same customers, FastYoke
connects them automatically. No setup required.

For example, with both the CRM Suite and the Field Service app installed,
every customer's detail page gains:

- an **HVAC Jobs** panel listing the field-service work for that customer,
  each with its live status, and
- a **Create a New Job** button that dispatches new work already linked to
  the customer.

The same applies to the Auto Dealer app (**Repair Orders**) and Urgent Care
(**Visits**). The connection appears the moment both apps are installed and
disappears if you uninstall one — there is nothing to configure.

Work you create from a customer is permanently linked back to that customer,
so the history stays accurate over time.
