# Quiz M16 — Capstone framing

Pairs with [Lecture M16](/docs/training/lectures/M16-capstone)
and [Lab M16](/docs/training/labs/M16-capstone).

**Q1.** What does the capstone reward most?

a) Feature count
b) Integration across primitives — the seams
c) Surface polish
d) Documentation length

<details>
<summary>Answer + why</summary>

**b)** A small Yoke that connects every primitive beats a
sprawling one with seams that don't connect.

</details>

**Q2.** What's the real exit criterion?

a) Self-attestation
b) A second learner can install + walk through your Yoke end-to-end
c) Passing an LLM grader
d) A maintainer's review

<details>
<summary>Answer + why</summary>

**b)** Reviewability by a second learner is the
load-bearing test.

</details>

**Q3.** What's the project deliverable?

a) A reference implementation of the FastYoke engine
b) One Tenant Yoke that exercises every primitive across Weeks 1–7
c) A capstone exam
d) A blog post

<details>
<summary>Answer + why</summary>

**b)** A Tenant Yoke that integrates the primitives you've
touched.

</details>

**Q4.** Why is there no starter code?

a) Budget reasons
b) Reaching for a template short-circuits the integration work
c) Coming soon
d) Available only on Enterprise

<details>
<summary>Answer + why</summary>

**b)** The rubric reads the integration, not the surface
polish. Templates anchor learners.

</details>

**Q5.** Where do the rubric categories come from?

a) Random
b) The primitives covered across Weeks 1–7 (schema, authoring, runtime, distribution, ops)
c) Cohort-specific
d) The instructor

<details>
<summary>Answer + why</summary>

**b)** Each rubric category maps to a week.

</details>

**Q6.** Scoping the capstone — better to ship…

a) A large project with many features
b) A small, well-integrated project with tight wiring
c) A demo only
d) A PowerPoint deck

<details>
<summary>Answer + why</summary>

**b)** Integration wins. Feature count doesn't.

</details>

**Q7.** Should you skip the documentation pass?

a) Yes — code speaks for itself
b) No — "a second learner can install it" is a real test
c) Only if you have time
d) Documentation is auto-generated

<details>
<summary>Answer + why</summary>

**b)** Without docs, the exit criterion fails.

</details>

**Q8.** What's the right way to use the capstone walkthrough (if shipped later)?

a) Copy directly
b) Read after submission to compare approaches
c) Skip — irrelevant
d) Required reading before starting

<details>
<summary>Answer + why</summary>

**b)** Anchoring early defeats the integration practice.

</details>

**Q9.** Capstone reviewers score…

a) Polish and aesthetics
b) Integration across primitives
c) Feature count
d) Documentation length

<details>
<summary>Answer + why</summary>

**b)** Wiring quality is what the rubric reads.

</details>

**Q10.** When are you done with the training?

a) When the syllabus is read
b) When every rubric category meets or exceeds and a second learner can install your Yoke cold
c) After 8 weeks regardless
d) When the labs pass

<details>
<summary>Answer + why</summary>

**b)** Two-part exit: rubric scores + reviewable install.

</details>
