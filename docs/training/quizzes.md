# About the quizzes

Sixteen self-check question banks, one per syllabus
module. **10 multiple-choice questions per module** with
revealed answers. They're a self-check, not an exam —
nothing is graded, nothing is tracked. The signal is
whether you can answer cold without peeking.

## How to use them

- **After the lab.** Take the quiz the same day you
  finish the matching lab. Recall is freshest, and the
  gaps you discover are still cheap to fix.
- **Click the reveal.** Each question has an `Answer +
  why` reveal. Read your explanation before clicking
  — the value is in *predicting* the explanation, not
  reading it.
- **Mark gaps for re-read.** A wrong answer is a
  pointer back to the lecture or the reference docs.

## Why no auto-grading

Two reasons. First, the questions test understanding,
not pattern matching — an LLM-graded quiz drifts toward
the answers an LLM-graded quiz can produce. Second, the
training is self-paced; there's no roster to grade
against. The honor system fits the audience.
