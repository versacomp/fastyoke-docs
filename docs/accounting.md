# Accounting

The [Yoke Ledger reference](/docs/yoke-ledger) tells you how
the General Ledger mechanism works. This section answers a
different question: **what does any of this mean for me?**

Two audiences land on this surface. They want the same
product framed differently:

- A **business owner** wants outcomes — "did I make money?",
  "where does this transaction go?", "what do I send my CPA?"
- An **accountant** or **bookkeeper** wants conventions —
  how to map an existing Chart of Accounts, what audit trail
  is preserved, how to close the books, how to export
  cleanly to QuickBooks.

Pick the angle you'd rather read in.
